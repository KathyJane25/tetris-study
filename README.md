# Tetris Iframe Widget

A small static Tetris game built as a single HTML file for iframe embedding.

## Local use

Open `index.html` in a browser.

## GitHub Pages iframe

After publishing this repository with GitHub Pages, embed it with:

```html
<iframe
  src="https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPOSITORY_NAME/"
  width="100%"
  height="760"
  style="border:0;max-width:560px;width:100%;"
  title="Tetris game"
  loading="lazy"
  allow="fullscreen">
</iframe>
```
